# HR-Employee-Attrition-Analysis-Dashboard
#Project Overview
This project focuses on analyzing employee attrition patterns using HR analytics data. The dashboard was created in Tableau to identify key factors affecting employee turnover and provide actionable business insights.
The analysis helps HR teams understand how factors such as job satisfaction, work-life balance, salary hike, department, and distance from home influence attrition.
#Objective
The main objective of this project is to:
Analyze employee attrition trends
Identify departments with high attrition
Understand factors influencing employee turnover
Support HR decision-making using data visualization
#Tools & Technologies Used
Power bi
CSV Dataset
Excel
SQL (for data analysis and preprocessing)
#Dataset Information
The dataset contains HR employee information including:
Employee Department
Job Satisfaction
Work-Life Balance
Monthly Income
Performance Rating
Distance From Home
Attrition Status
Salary Hike
Education Level
#Dataset Used: IBM HR Analytics Employee Attrition Dataset
#Dashboard Features
The dashboard includes:
Total Employees KPI
Average Income Analysis
Department-wise Attrition
Attrition by Distance From Home
Work-Life Balance Analysis
Job Satisfaction Analysis
Salary Hike vs Attrition
Performance Rating Distribution
Key Insights
Research & Development department showed the highest attrition.
Employees with lower work-life balance had higher attrition rates.
Employees living farther from the workplace showed slightly increased attrition.
Lower salary hikes were associated with higher employee turnover.
Job satisfaction had a significant impact on attrition behavior.
